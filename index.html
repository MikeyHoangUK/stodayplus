Why it works

Built on how memory actually works

No gimmicks. Three of the best-researched study methods in learning science, built into every session.

D1D3D7D14D28

Method 01

Spaced repetition

We forget much of what we learn within days. Reviewing at growing gaps (day 1, 3, 7, 14, 28) moves it into long-term memory. The planner schedules it for you.

✦ Retention on autopilot
Re-reading
Self-testing

Method 02

Active recall

Re-reading feels like learning but leaves little behind. Pulling an answer out of memory is what makes it stick, so every tool makes you produce the answer.

✦ Memory that lasts
LearnForgettingReview → kept

Method 03

Review before you forget

Memory fades fastest in the first few days. A quick review inside that window catches it before it drops, and explaining it simply (Finley) shows what you've really understood.

✦ Nothing slips through
